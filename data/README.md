# Data Directory

This directory contains all input data for the phyloresistomics pipeline. Subdirectories are organised as follows:

- `raw_fastq/` -- paired-end Illumina FASTQ files (git-ignored)
- `metadata/` -- clinical and epidemiological sample metadata (git-ignored)

All data files are excluded from version control. See the README in each subdirectory for details on expected file formats and naming conventions.
