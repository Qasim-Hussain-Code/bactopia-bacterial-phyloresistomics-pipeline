# Sample Metadata

This directory holds clinical and epidemiological metadata associated with the sequenced isolates.

Files in this directory are excluded from version control. Metadata files should include sample identifiers that match those used in `config/samples.tsv` to enable downstream integration with genomic results.

## Suggested fields

- Sample ID
- Species
- Isolation source
- Collection date
- Geographic origin
- Clinical phenotype or antibiotic susceptibility testing results
