# Results Directory

This directory contains all pipeline outputs, organised by analysis phase:

- `bactopia_output/` -- Bactopia core pipeline results (QC, assembly, annotation, typing, AMR)
- `phylo_trees/` -- maximum-likelihood phylogenies from IQ-TREE
- `resistome_matrices/` -- AMR and virulence gene presence/absence matrices
- `publication_figures/` -- final figures for manuscript preparation

Large output files are excluded from version control. See the README in each subdirectory for expected outputs.
