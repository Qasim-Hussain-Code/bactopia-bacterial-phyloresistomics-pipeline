# Publication Figures

This directory holds final figures generated for manuscript preparation or reporting.

## Expected outputs

- Phylogenetic tree with tip annotations (sequence types, clonal complexes)
- AMR resistome heatmap overlaid on phylogenetic tree topology
- Virulence factor distribution across the strain collection

Figures are generated using R (tidyverse, ComplexHeatmap) and are excluded from version control. To regenerate, run the visualisation step of the pipeline.
